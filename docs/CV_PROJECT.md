# Descripción sugerida para CV o portfolio

**Asistente comercial con IA — Python, FastAPI, PostgreSQL y JavaScript**

Desarrollo de una aplicación para gestionar pedidos mediante conversaciones: catálogo por negocio, cálculo de totales en el servidor, confirmación de pedidos, estados de pago y atención humana por chat. Integración opcional con modelos locales mediante Ollama o una API de IA, y adaptadores de WhatsApp Cloud API y Mercado Pago. Demo reproducible con Docker, datos aislados por visitante y pagos simulados. Pruebas automatizadas de validación, aislamiento y concurrencia durante la atención humana.

Al presentarlo, explicá qué partes implementaste y cuáles desarrollaste con asistencia, qué límites tiene y cómo verificaste su comportamiento. No declares usuarios reales, métricas comerciales, certificación de Meta ni despliegue productivo si todavía no existen.
